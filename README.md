# SANBRO Chess

A React + TypeScript implementation of **SANBRO Chess** with a galactic-blue UI, authentication, home page, and playable chess interface.

## Features included
- Home page with chess history/rules and **PLAY CHESS** CTA.
- Name-only sign in/sign up with localStorage.
- Light-blue / dark-blue chessboard and highlighted states (last move, check, valid move hints).
- Drag-and-drop and click-to-move.
- Move history with analysis badges.
- Opening/trap detector banner (starter opening map).
- Evaluation bar (material-based percentage).
- Undo, Redo, Switch sides, Resign, New game, Hint controls.
- Suggestion/attack arrows via toggles.
- Timer presets including unlimited.
- Side selection: White / Black / Random.
- 2-player and AI (random legal move baseline).
- Bot catalog from 50-4000 ELO including **Polu** and **Neel**.
- Bot chat + coach-like hint panel.
- Checkmate and draw state indicators.

## Run locally
```bash
npm install
npm run dev
```
